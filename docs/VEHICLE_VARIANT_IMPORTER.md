# Универсальный импортёр точных модификаций

## Поток работы

1. Добавить JSON-файл в \`src/data/packs/<марка>/<модель>.json\`.
2. Указать \`schemaVersion: 1\` и массив \`variants\`.
3. Для каждой модификации заполнить точную идентичность: \`modelId\`, \`generationId\`, рынок, год, код кузова, двигатель, тип КПП и привод.
4. Для каждого источника указать название, URL, тип, рынок, область применимости и дату фактического доступа.
5. Неизвестные поля не заполнять нулями, предположениями или общими значениями. Указать их в \`limitations[]\`.
6. Запустить \`npm run import:vehicles\`; затем \`npm run audit:variants\` или полный \`npm run check\`.

## Защита качества

- \`modelId\` должен существовать в каноническом каталоге приложения.
- \`generationId\` должен существовать в индексе поколений и быть связан с тем же \`modelId\`.
- Идентификаторы модификаций и точные комбинации идентичности должны быть уникальны.
- Числовые характеристики должны быть положительными; ноль не используется как обозначение неизвестного значения.
- \`verified\` требует полного источника первичного уровня. Drom/Auto.ru учитываются как вторичные справочники и не повышают статус до \`verified\`.
- \`partially-verified\` требует источники, подтверждающие хотя бы часть полей.
- Импортёр не скачивает сайты, не обходит ограничения и не придумывает отсутствующие значения. Он нормализует уже собранные данные и останавливается при ошибках.
- Результат генерируется в \`src/data/vehicleVariantPacks.generated.ts\`; ручные изменения этого файла будут перезаписаны.

Пример структуры пакета находится в комментариях и файлах-образцах каталога \`src/data/packs\`.
