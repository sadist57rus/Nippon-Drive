## Выводы

### 1. Toyota RAV4 XA30 — записи 51–67 (17)

**Что подтверждено первичными материалами:**
- Toyota Europe подтверждает третье поколение RAV4, европейский запуск в 2006 году и доступность бензиновых и дизельных двигателей. Официальный британский launch pack приводит технические параметры 2.0 VVT-i и дизельных версий.
- Для европейского дизельного ALA30 официальная европейская программа ТО перечисляет двигатель 2AD-FTV для 2.2 D-4D и отдельно 2AD-FHV для 2.2 D-CAT.
- Toyota Global подтверждает для японского короткобазного RAV4 ACA31W/ACA36W другой набор: 2AZ-FE 2.4. Это не следует смешивать с европейскими длиннобазными ACA35/ALA30.

**Блокирующее несоответствие:**
- Записи **66–67** обозначены как **2.2 D-CAT**, мощность 177, но двигатель указан **2AD-FTV**. Официальная европейская матрица относит 2.2 D-CAT к **2AD-FHV**, а 2AD-FTV — к 2.2 D-4D. Не исправлять код молча: отметить обе строки как требующие исправления и повторной генерации ID только после отдельного решения, поскольку ID содержит код двигателя.

**Дополнительное ограничение:**
- В записях 51–60 `powerHp: 152`, в 61–65 `powerHp: 136`. Официальная спецификация Toyota UK использует одновременно bhp и DIN hp/PS. Значения в пакете похожи на PS, но поле называется `powerHp`. До стандартизации единиц не считать эти цифры нормализованными hp.
- У всех 17 записей в limitations вынесены размеры, шины, диски, щётки и момент — это правильно; не заполнять их из общего поколения без привязки к комплектации.

### 2. Toyota RAV4 XA40 — записи 68–85 (18)

**Что подтверждается на уровне модельной матрицы:**
- Drom показывает российские комплектации с кодами кузова ZSA42/ZSA44 (3ZR-FE, 2.0), ALA49 (2AD-FTV, 2.2D) и ASA44 (2AR-FE, 2.5). Эти строки согласуются с заявленными типами привода/коробки в каталоге Drom.
- Это только вторичное сопоставление. В найденных материалах Toyota Global для третьего поколения нет первичной таблицы, которая подтверждала бы каждую российскую комплектацию XA40 из диапазона 68–85.

**Что оставить неподтверждённым:**
- Для всех 18 строк точные интервалы выпуска и названия российских grade необходимо подтвердить архивными прайс-листами/брошюрами Toyota Россия по модельным годам.
- Для 2.0 CVT нельзя переносить применяемость вариатора между FWD и 4WD без соответствующей таблицы рынка.
- Поле `powerHp: 146` может быть значением в PS, а не механических hp; до унификации единиц оставить ограничение.
- Не менять `modelId` или `generationId` в рамках этого аудита.

### 3. Toyota Camry XV40 — записи 86–90 (5)

- Toyota Global подтверждает для ACV40 двигатель 2AZ-FE, 2 362 см³ и 167 PS; официальный архив также указывает, что это японская модельная спецификация.
- Пакет содержит ACV40 с 2AZ-FE (четыре комплектации) и GSV40 с 2GR-FE (одна комплектация). Данные по ACV40 согласуются по коду/объёму/мощности на уровне двигателя, но не подтверждают российские названия комплектаций и точные периоды каждой строки.
- Для 2GR-FE/GSV40 требуется отдельная первичная спецификация рынка Россия; японская таблица ACV40 не подтверждает GSV40.
- Значение 167 в поле `powerHp` требует проверки единиц: Toyota публикует 167 **PS**, а не 167 механических hp. Аналогично 277 для 2GR-FE нужно проверить по рынку и единицам.

### 4. Honda CR-V RE — записи 91–94 (4)

- Официальный сайт Honda Россия хранит регламент ТО для CR-V (RE5, RE7) 2007 года; в нём отдельно перечислены моторы R20A и K24Z, а также расходники для MT/AT.
- Это поддерживает наличие R20A в российской линейке RE5, но в документе двигатель дан как семейство R20A, а не точный суффикс R20A2. Код R20A2, мощность 150 и конкретные сочетания Comfort/Elegance/Executive требуют подтверждения каталогом/брошюрой для российского рынка.
- Не переносить прежнее замечание о K24Z1 на эти четыре строки: здесь указан R20A2, это другая модификация двигателя. Не заменять R20A2 на R20A без документального основания.

### 5. Mazda CX-5 KE — записи 95–100 (6)

- Mazda Newsroom для японского CX-5 2012 подтверждает PE-VPS 1 997 см³, 155 PS и 196 Н·м, а также сочетания FWD/4WD с 6-ступенчатой автоматической трансмиссией для соответствующих японских grade.
- Официальная российская брошюра CX-5 2.0 указывает 150 л.с. и 213 Н·м, с 6MT/6AT и 2WD/4WD. Это ближе к рынку записей в пакете и объясняет отличие от японской калибровки.
- Найденная российская брошюра не доказывает сама по себе, что она относится к каждому году и каждому grade 2011–2015. Для точной привязки нужны архивные брошюры по модельным годам/рестайлингу.
- Значения 150 л.с. для российского PE-VPS можно считать согласующимися с официальной брошюрой по двигателю, но пока не подтверждёнными для всех шести комбинаций trim/год/коробка/привод.
