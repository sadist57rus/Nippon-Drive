## Ограничения и следующий этап

Это экспорт уже находящихся в репозитории индексов, а не полная выгрузка всех страниц источников. Нельзя трактовать его как готовую техническую базу модификаций.

Drom предоставляет публичные страницы марок и моделей, а также отдельные разделы двигателей и кузовов. Каталог Toyota, например, содержит отдельные страницы моделей и ссылки на двигатели и кузова. Для массового обхода страниц нужен сетевой исполнитель с аккуратным ограничением частоты запросов.

В документации официального API Auto.ru описан метод `GET /1.0/search/cars/breadcrumbs`, который возвращает уровни марка → модель → поколение → конфигурация → технические параметры. Пример запроса использует заголовок `x-authorization`. Поэтому полноценный сбор через API требует действующего ключа доступа. Ключ нельзя помещать в репозиторий или экспорт.

Следующий проход должен дополнить этот снимок данными по отдельным конфигурациям и рынкам: двигатель, мощность, коробка, привод, кузов, годы выпуска, затем габариты и колёсные параметры. Незаполненные поля остаются пустыми до подтверждения источником; нули не используются как заглушки.
