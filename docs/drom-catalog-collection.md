# Сбор исходных данных Drom

## Запуск

В GitHub Actions выберите workflow **Drom catalogue source collection** и вручную запустите один из режимов:

- `sitemap-inventory` — обнаружение публичных URL XML-карт каталога;
- `html-samples` — получение ограниченного набора публичных HTML-страниц для анализа разметки.

Результаты сохраняются как артефакты Actions на 14 дней. HTML-образцы не коммитятся в репозиторий.

## HTML-образцы

Режим `html-samples` получает три фиксированные публичные страницы Corolla: модель, комплектации 2026 года и таблицу трансмиссий. Запросы выполняются последовательно с паузой 1,5 секунды, тайм-аутом 30 секунд и ограничением ответа 8 МиБ. В manifest сохраняются конечный URL, HTTP-статус, Content-Type, размер и SHA-256. Ошибки HTTP, блокировки и неожиданный тип содержимого фиксируются; обход ограничений не выполняется.

## Ограничения

Инвентаризация URL не является извлечением технических характеристик. HTML-образцы нужны только для анализа реальной DOM-разметки; поля нельзя считать подтверждёнными до проверки точной модификации, рынка и применимости. Неизвестные значения остаются пустыми, нули не используются как заглушки. Drom и Auto.ru — вторичные справочные источники, а не основание автоматически присваивать статус verified.

Скрипты не обращаются к закрытым API и не пытаются обходить авторизацию, CAPTCHA или ограничения доступа.
