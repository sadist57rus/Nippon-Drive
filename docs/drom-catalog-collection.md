# Сбор исходных данных Drom

## Запуск

В GitHub Actions выберите workflow **Drom catalogue source collection** и запустите вручную с вариантом `sitemap-inventory`.

Workflow использует публичные XML-карты каталога Drom. API Auto.ru и ключ авторизации не требуются. Запросы выполняются последовательно с паузой, результаты сохраняются как артефакт Actions на 14 дней.

## Что собирается на первом проходе

- URL-карты марок, моделей, поколений и комплектаций;
- сводные страницы характеристик;
- индексы двигателей и годов выпуска;
- отдельный список URL, которые удалось отнести к японским маркам.

## Ограничения

Первый проход — только обнаружение URL. Он **не является** извлечением технических характеристик и не изменяет офлайн-каталог приложения. URL не считаются доказательством конкретного двигателя, коробки, привода или размеров. Следующий этап — разбор страниц поколений/комплектаций с сохранением рынка, точной модификации, исходного URL и необязательных полей. Неподтверждённые значения остаются пустыми; нули не используются как заглушки.

Скрипт намеренно не обращается к закрытым API и не пытается обходить авторизацию или ограничения доступа.
