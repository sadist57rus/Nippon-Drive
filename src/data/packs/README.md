# Пакеты точных модификаций

Помещайте сюда JSON-пакеты (можно создавать подпапки по марке/модели). Импортёр рекурсивно читает все файлы с расширением .json.

Контракт пакета: объект с `schemaVersion: 1` и массивом `variants`. Каждая запись описывает одну точную комбинацию рынка, поколения/кузова, года, двигателя, КПП и привода. Поля, которые нельзя подтвердить, не заполняются нулями: оставляйте их отсутствующими и добавляйте причину в `limitations`.

Команда `npm run import:vehicles` проверяет все пакеты и пересобирает `src/data/vehicleVariantPacks.generated.ts`. Не редактируйте generated-файл вручную.
